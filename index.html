Settings

Stored on this phone only. Nothing is sent anywhere else.

Give the token access to that one repo only, with Contents: Read and write and nothing else. It never leaves this phone — captures are sent straight to GitHub from here, with no server in between.

What you can say

Say it however you actually say it. Nothing is ever dropped.

  • the timer should flash before food burns — just a thought
  • create folder chicken rack — makes a folder to think in
  • reference folder chicken rack — later thoughts go in it
  • add to chicken rack: it should fold flat — one note
  • product idea: … / ai build: … — scaffolds a folder
  • add image to social command center — stages an action
  • bug in order tracker: … — files as a defect
This app only stores your words. Folders and actions are created at the PC when you run /triage — so a capture can never fail just because something else is unreachable.
